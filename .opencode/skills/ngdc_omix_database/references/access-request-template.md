# OMIX controlled-access request (editable template)

> Use only for controlled-access records. A dataset may require a separate online application, rather than an email. Confirm the actual process on its OMIX record page and with the custodian. Do not send an unreviewed draft.

**Subject:** Access application for OMIX[ACCESSION] — [PROJECT TITLE]

Dear [data submitter / data access committee],

I am requesting access to dataset **OMIX[ACCESSION]**, titled **[DATASET TITLE]**, for the research project **[PROJECT TITLE]** at **[INSTITUTION]**.

**Applicant:** [Name, position, official institutional email]  
**Principal investigator:** [PI name and contact]  
**Institution / department:** [Details]  
**Ethical approval / protocol:** [Protocol number, approving authority, or why not applicable]  
**Files / data required:** [Exact file IDs; justify each]  
**Scientific aims:** [Research question and importance]  
**Methods:** [Planned analysis]  
**Users and collaborators:** [Authorized personnel only]  
**Intended use period:** [Dates]  
**Data security:** [Secure storage, access restrictions, retention/deletion plan, authorized environment]  
**Legal/institutional permissions:** [Approvals and agreements, as applicable]

I will use the data only within the approved scope, follow relevant consent and regulatory restrictions, not attempt to identify participants, and not redistribute data beyond the terms of the approved agreement. Please advise whether other documentation or a formal online application is required.

Thank you,  
[Name]  
[Institution]  
[Contact]

---

**Before submitting:** Verify the correct recipient, official application path, record status, and any dataset-specific restrictions. Never include sensitive human-level data in an email application unless the custodian expressly requires it through a secure channel.
